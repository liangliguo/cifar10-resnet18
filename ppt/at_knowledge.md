# 对抗攻击与对抗训练知识文档

本文档对应 `at.tex` 这份 PPT，重点解释“模型训练”之后的内容：DeepFool 对抗攻击、攻击实验结果、PGD 对抗训练、防御评估与总结。写作假设是：读者不了解对抗样本、梯度攻击、鲁棒性评估等概念，因此会先解释基本概念，再解释公式和实验结论。

## 1. 模型训练之后，我们已经有什么？

PPT 前半部分完成了一件事：在 CIFAR-10 数据集上训练一个 ResNet-18 分类模型。

CIFAR-10 是一个 10 分类图像数据集，类别包括 airplane、automobile、bird、cat、deer、dog、frog、horse、ship、truck。每张图片大小是 `32 x 32`，模型输入一张图片后，会输出 10 个类别分数，分数最高的类别就是模型预测结果。

训练完成后，基线模型在干净测试集上的 Top-1 准确率是：

```text
Clean Acc = 88.53%
```

这里的“干净测试集”指没有被攻击、没有额外扰动的原始测试图片。

从模型训练之后开始，PPT 主要研究两个问题：

1. 攻击：如果对图片加入很小的扰动，模型会不会被诱导产生错误分类？
2. 防御：如果训练时就让模型接触对抗样本，模型能否变得更鲁棒？

可以把后半部分理解为：

```text
普通模型 -> 对抗攻击评估 -> 发现模型脆弱
普通模型 -> PGD 对抗训练 -> 得到鲁棒模型 -> 再次评估防御效果
```

## 2. 先理解几个基础概念

### 2.1 分类器、logits 与预测标签

分类模型可以记为：

```math
f(x)
```

其中 `x` 是输入图片，`f(x)` 是模型输出的类别分数。对 CIFAR-10 来说，模型会输出 10 个分数。通常把这些未经过 softmax 的类别分数称为 logits。

模型最终预测的类别是分数最大的那一类：

```math
\hat{k}(x) = \arg\max_k f_k(x)
```

含义是：在所有类别 `k` 中，选择分数 `f_k(x)` 最大的类别。

### 2.2 损失函数

训练分类模型时，我们希望正确类别的分数高，错误类别的分数低。衡量“模型预测与真实标签差距”的函数叫损失函数，PPT 中主要使用交叉熵损失：

```math
L(f_\theta(x), y)
```

其中：

- `x` 是图片。
- `y` 是真实标签。
- `f_\theta` 是参数为 `theta` 的模型。
- 损失越大，说明模型在该样本上的预测越差。

### 2.3 梯度

梯度可以理解为“让某个量增长最快的方向”。

在对抗攻击里，我们经常计算：

```math
\nabla_x L(\theta, x, y)
```

它表示：如果稍微改变输入图片 `x`，损失函数会如何变化。

如果沿着梯度方向修改图片，通常会使损失变大，也就是让模型更容易出错。因此很多攻击方法都基于梯度。

### 2.4 扰动

扰动记为：

```math
r
```

它表示加到原图上的微小变化。对抗样本就是：

```math
x + r
```

如果 `r` 很小，人眼看起来几乎没有变化，但模型预测发生错误，那么 `x + r` 就是对抗样本。

### 2.5 范数：如何衡量扰动大小

扰动大小需要用数学方式度量，常见的是两种范数。

`L_2` 范数：

```math
\|r\|_2
```

可以理解为扰动的欧几里得长度，类似普通空间中的距离。

`L_\infty` 范数：

```math
\|r\|_\infty
```

关注所有像素变化里最大的那个变化量。固定 `L_\infty` 预算时，常见设置是：

```math
\varepsilon = 8/255
```

这表示每个像素最多只能改变 `8/255`。

### 2.6 决策边界

模型会把输入空间划分成不同类别区域。例如某些图片会被分为 cat，另一些会被分为 dog。类别区域之间的分界面叫决策边界。

如果一张图片离决策边界很近，只需要很小扰动就能把它推到另一个类别区域，模型就容易被攻击。

因此，很多鲁棒性分析都可以转化为：

```text
样本距离决策边界有多远？
```

距离越近，越不鲁棒；距离越远，越鲁棒。

## 3. 什么是对抗攻击？

对抗攻击的目标是：在图片上加入尽量小的扰动，使模型预测发生改变。

形式化写法是：

```math
\Delta(x; f) := \min_r \|r\|_2
\quad \text{s.t.} \quad \hat{k}(x+r) \neq \hat{k}(x)
```

逐项解释：

- `r` 是要寻找的扰动。
- `\|r\|_2` 是扰动大小。
- `min` 表示希望扰动尽可能小。
- 约束 `\hat{k}(x+r) != \hat{k}(x)` 表示扰动后模型预测类别必须改变。

这个问题的核心就是：

```text
找一个最小扰动，使模型改变预测。
```

DeepFool 就是围绕这个目标设计的攻击方法。

## 4. FGSM：最基本的梯度攻击

在讲 DeepFool 前，PPT 先回顾了 FGSM。

FGSM 全称是 Fast Gradient Sign Method。它只执行一步更新：

```math
r = \varepsilon \cdot \text{sign}(\nabla_x J(\theta, x, y))
```

解释如下：

- `J` 或 `L` 都表示损失函数。
- `\nabla_x J` 是损失对输入图片的梯度。
- `sign` 只保留梯度方向的正负号。
- `epsilon` 是扰动预算，控制每个像素最大能改多少。

FGSM 的思路非常直接：

```text
朝着让损失增加最快的方向，对每个像素改动 epsilon。
```

FGSM 的优点：

- 只需要一步，速度快。
- 思路简单，容易实现。

FGSM 的局限：

- 它不是为了寻找最小扰动，而是在固定预算 `epsilon` 下直接攻击。
- `sign` 操作会让很多像素都达到最大扰动幅度，扰动可能偏大。
- `epsilon` 需要人工指定。

因此，FGSM 更像是“固定预算攻击”，而不是“最小扰动攻击”。

## 5. DeepFool：寻找最小扰动

### 5.1 DeepFool 的目标

DeepFool 的目标是自动寻找使样本刚好跨过决策边界的最小扰动。

它回答的问题是：

```text
这张图片离模型决策边界到底有多远？
```

如果 DeepFool 只需要很小扰动就能改变模型预测，说明模型在该样本附近鲁棒性较低。

### 5.2 DeepFool 的几何直觉

深度神经网络整体是非线性的，决策边界通常很复杂。但在某个样本附近，可以用局部线性近似把边界看作一个超平面。

二维情况下，可以把决策边界想成一条线；高维情况下，对应的是超平面。

如果要用最小距离越过一条平面边界，最短方向就是垂直于边界的方向。这就是“点到平面的最短距离”。

DeepFool 的核心机制是：

```text
每次把当前点附近的复杂边界近似成线性边界，
然后计算到最近边界的垂直投影，
再更新样本位置，重复直到预测类别改变。
```

### 5.3 二分类线性情形

先看最简单情况。假设二分类器是线性的：

```math
f(x) = w^T x + b
```

决策边界是：

```math
f(x) = 0
```

样本 `x` 到这个超平面的最小扰动是：

```math
r_*(x) = - \frac{f(x)}{\|w\|_2^2} w
```

解释：

- `w` 是超平面的法向量，也就是垂直于边界的方向。
- `f(x)` 表示当前点离边界的有符号距离量。
- `\|w\|_2` 用于把方向和距离归一化。

这个公式的含义是：

```text
沿着边界的垂直方向，把样本移动到决策边界上。
```

### 5.4 二分类非线性情形

真实神经网络不是线性的，所以不能直接用一个固定超平面描述全局边界。

DeepFool 的做法是：在当前点 `x_i` 附近对模型做一阶近似：

```math
f(x_i + r) \approx f(x_i) + \nabla f(x_i)^T r
```

这表示把复杂函数在当前点附近近似成一个线性函数。

然后计算当前局部线性边界下的最小扰动：

```math
r_i = - \frac{f(x_i)}{\|\nabla f(x_i)\|_2^2} \nabla f(x_i)
```

并更新：

```math
x_{i+1} = x_i + r_i
```

由于神经网络边界是弯曲的，一步可能不够，所以 DeepFool 会重复：

```text
线性化 -> 计算最小扰动 -> 更新样本 -> 再线性化
```

直到模型预测类别发生改变。

### 5.5 多分类情形

CIFAR-10 是 10 分类任务，不是二分类。

对多分类模型，当前预测类别记为：

```math
\hat{k}(x_0)
```

对每个其他类别 `k`，DeepFool 都会估计“当前类别”和“类别 k”之间的边界。

定义：

```math
w'_k = \nabla f_k(x_i) - \nabla f_{\hat{k}(x_0)}(x_i)
```

```math
f'_k = f_k(x_i) - f_{\hat{k}(x_0)}(x_i)
```

含义：

- `w'_k` 表示类别 `k` 与当前类别之间边界的法向方向。
- `f'_k` 表示当前点相对于该边界的距离量。

然后 DeepFool 选择最近的边界：

```math
\hat{l} = \arg\min_{k \neq \hat{k}(x_0)}
\frac{|f'_k|}{\|w'_k\|_2}
```

也就是在所有可能让类别改变的边界中，选择距离最近的那个。

本步扰动为：

```math
r_i =
\frac{|f'_{\hat{l}}|}{\|w'_{\hat{l}}\|_2^2} w'_{\hat{l}}
```

### 5.6 overshoot：为什么要过冲？

DeepFool 理论上会把样本推到决策边界附近。但如果样本刚好停在边界上，数值误差或图像量化可能导致它仍被判为原类别。

因此 DeepFool 会使用一个小的过冲系数：

```math
\hat{r} = (1 + \eta)\sum_i r_i
```

PPT 中设置：

```math
\eta = 0.02
```

也就是最后把累计扰动乘以 `1.02`，使样本略微越过边界。

### 5.7 本实验中的 DeepFool 设置

PPT 中使用：

```text
torchattacks.DeepFool(steps=20, overshoot=0.02)
```

含义：

- `steps=20`：最多迭代 20 步。
- `overshoot=0.02`：扰动最终乘以 `1.02`。

DeepFool 每一步都需要对多个类别求梯度，所以比 FGSM 慢。CIFAR-10 只有 10 类，计算仍然可控，但全量 10000 张测试集会比较耗时，因此 PPT 中 DeepFool 使用 1000 张样本进行评估。

## 6. 攻击实验如何评价？

### 6.1 不同攻击关注的指标不同

固定预算攻击，例如 FGSM、PGD、APGD，通常关心：

```text
在给定 epsilon 内，模型还剩多少准确率？
```

这就是 Robust Acc。

最小扰动攻击，例如 DeepFool，更关心：

```text
让模型改变预测到底需要多大扰动？
```

因此 DeepFool 的关键指标是平均或中位 `L_2` 扰动，以及相对扰动。

### 6.2 Clean Acc

Clean Acc 是模型在原始测试集上的准确率。

普通模型：

```text
Clean Acc = 88.53%
```

鲁棒模型：

```text
Clean Acc = 86.25%
```

对抗训练后，Clean Acc 通常会下降一点。这是鲁棒性和干净准确率之间的常见权衡。

### 6.3 Robust Acc

Robust Acc 是模型在对抗样本上的准确率。

如果攻击后模型仍然分类正确，那么该样本对当前攻击是鲁棒的。

举例：

```text
Robust Acc = 45%
```

含义是：在这种攻击下，仍有 45% 的样本能被正确分类。

### 6.4 条件攻击成功率

PPT 中的攻击成功率采用条件口径：

```text
条件攻击成功率 = 干净样本上分类正确、经攻击后变为误分类的比例
```

这很重要，因为如果模型本来就把某张干净图片分错了，就不能算攻击成功。

### 6.5 平均 L2 扰动

平均 `L_2` 扰动表示平均需要多大扰动才能让模型预测改变。

数值越小，说明模型越容易被攻击。

PPT 中 DeepFool 的平均 `L_2` 约为：

```text
0.1606
```

比 FGSM 和 APGD 的平均 `L_2` 小很多。

### 6.6 相对扰动 rho_adv

DeepFool 论文中使用平均相对扰动：

```math
\hat{\rho}_{adv}(f)
=
\frac{1}{|\mathcal{D}|}
\sum_{x \in \mathcal{D}}
\frac{\|\hat{r}(x)\|_2}{\|x\|_2}
```

解释：

- `\|\hat{r}(x)\|_2` 是扰动大小。
- `\|x\|_2` 是原图大小。
- 二者相除得到相对扰动比例。

为什么要除以 `\|x\|_2`？

因为不同图片本身的整体幅度可能不同。相对扰动可以让不同样本之间更可比。

## 7. 攻击实验结果如何解读？

PPT 中三种攻击对普通模型的结果如下：

| 攻击 | 范数 / 预算 | 攻击成功率 | Robust Acc | 平均 L2 | rho_adv |
|---|---:|---:|---:|---:|---:|
| FGSM | L_inf, 8/255 | 96.01% | 3.57% | 1.7233 | 0.0628 |
| DeepFool | L2 最小扰动 | 97.60% | 2.15% | 0.1606 | 0.0057 |
| APGD | L_inf, 8/255 | 100.00% | 0.00% | 1.2876 | 0.0467 |

### 7.1 结论一：普通模型几乎没有鲁棒性

FGSM 下 Robust Acc 只有：

```text
3.57%
```

APGD 下 Robust Acc 是：

```text
0.00%
```

说明普通模型面对强攻击时几乎完全失效。

### 7.2 结论二：DeepFool 用更小扰动达到相近攻击效果

DeepFool 的攻击成功率是：

```text
97.60%
```

与 FGSM 接近，但平均 `L_2` 只有：

```text
0.1606
```

而 FGSM 平均 `L_2` 是：

```text
1.7233
```

DeepFool 的扰动约为 FGSM 的 `1/11`。这说明普通模型的决策边界距离样本非常近，只需要很小扰动就能改变预测。

### 7.3 为什么 APGD 成功率最高？

APGD 是更强的固定预算攻击。它会在 `L_inf` 预算内自适应调整步长，并尝试更有效地最大化损失。

因此 APGD 可以把普通模型的 Robust Acc 压到 0。

但 APGD 的目标不是最小扰动，而是在给定预算内尽可能攻击成功。

## 8. 如何理解几类可视化结果？

### 8.1 对抗样本三联图

PPT 中对抗样本可视化一般包含三部分：

```text
原图 | 对抗图 | 放大后的扰动
```

要点：

- 原图人眼可识别，模型也分类正确。
- 对抗图在人眼看来几乎没变，但模型预测变成相邻类别。
- 扰动需要放大后才能看清。

这说明模型关注的判别特征和人眼感知并不完全一致。

### 8.2 L2 分布图

L2 分布图比较 FGSM 与 DeepFool 的扰动大小。

如果 DeepFool 的分布整体更靠近 0，说明：

```text
DeepFool 找到的扰动更小。
```

这支持“DeepFool 属于最小扰动评估范式”的结论。

### 8.3 混淆矩阵

混淆矩阵可以看模型把真实类别预测成什么类别。

干净测试集上，混淆矩阵对角线较强，表示大部分样本预测正确。

对抗样本上，对角线显著变弱，表示很多原本正确的样本被推向其他类别。

这说明攻击不是只影响少数类别，而是系统性地降低了模型分类能力。

### 8.4 t-SNE 图

t-SNE 用于把高维特征压缩到二维平面，方便可视化。

干净样本上，不同类别通常会形成相对清晰的簇。

攻击后，类别簇结构被扰动，很多样本移动到其他类别区域附近。

这说明攻击不仅改变最终分类结果，也改变了模型内部特征空间中的样本分布。

## 9. 为什么需要对抗训练？

攻击实验已经说明：普通模型在对抗样本上非常脆弱。

对抗训练的想法是：

```text
训练时不仅看干净样本，也让模型学习最坏情况下的对抗样本。
```

如果模型在训练过程中不断接触难样本，它就可能学到更稳定的决策边界。

## 10. PGD 对抗训练

### 10.1 min-max 形式

对抗训练可以写成：

```math
\min_\theta
\mathbb{E}_{(x,y)}
\left[
\max_{\|\delta\|_\infty \le \varepsilon}
L(f_\theta(x+\delta), y)
\right]
```

这是一个 min-max 问题。

内层：

```math
\max_{\|\delta\|_\infty \le \varepsilon}
L(f_\theta(x+\delta), y)
```

含义是：在扰动预算内，寻找最能让模型出错的扰动。

外层：

```math
\min_\theta
```

含义是：更新模型参数，让模型即使面对内层找到的最坏扰动，也能降低损失。

通俗地说：

```text
先找当前模型最难处理的对抗样本，
再用这些对抗样本训练模型。
```

### 10.2 PGD 是什么？

PGD 全称是 Projected Gradient Descent。虽然名字里有 Descent，但在攻击里它用于迭代增加损失。

更新公式是：

```math
x^{t+1}
=
\Pi_{\mathcal{B}_\varepsilon(x)}
\left(
x^t + \alpha \cdot
\text{sign}(\nabla_x L(\theta, x^t, y))
\right)
```

逐项解释：

- `x^t` 是第 `t` 步的对抗样本。
- `alpha` 是每一步的步长。
- `sign(gradient)` 表示沿损失增加方向更新。
- `Pi` 是投影操作。
- `B_epsilon(x)` 是以原图 `x` 为中心、半径为 `epsilon` 的扰动预算集合。

PGD 的流程是：

```text
随机初始化 -> 沿梯度增加损失 -> 投影回预算范围 -> 重复多步
```

### 10.3 为什么需要投影？

如果只沿梯度一直更新，扰动可能超过允许范围，图片会变化过大。

投影操作保证：

```math
\|x^t - x\|_\infty \le \varepsilon
```

也就是每一步之后，对抗样本仍然在合法扰动预算内。

同时还要保证像素值仍在：

```math
[0, 1]
```

### 10.4 随机起点的作用

PGD 通常从：

```math
x^0 = x + \text{Uniform}(-\varepsilon, \varepsilon)
```

开始，而不是总从原图开始。

这样做可以减少攻击陷入某个固定路径的风险，也有助于排查梯度混淆。

### 10.5 本实验中的 PGD 设置

训练时使用：

```text
PGD-7
epsilon = 8/255
```

评估时使用更强的：

```text
PGD-20
alpha = 2/255
random restart
```

训练时使用 PGD-7 是因为对抗训练本身计算成本很高。如果每个 batch 都使用太强的攻击，训练会非常慢。

评估时使用 PGD-20 是为了更严格地测试模型。

## 11. 为什么训练用 PGD，而不是 DeepFool？

这是 PPT 中非常重要的一点。

### 11.1 PGD 适合训练

PGD 的目标是：

```text
在固定 epsilon 预算内最大化损失。
```

这正好对应对抗训练的内层最大化问题：

```math
\max_{\|\delta\|_\infty \le \varepsilon} L(f_\theta(x+\delta), y)
```

因此 PGD 生成的是“固定预算下的强对抗样本”，适合用于训练模型。

### 11.2 DeepFool 更适合评估

DeepFool 的目标是：

```text
寻找刚好改变类别所需的最小扰动。
```

这类样本通常位于决策边界附近，扰动大小不统一，也没有固定 `epsilon` 预算。

因此 DeepFool 更适合作为评估工具，用来测量样本到决策边界的距离，而不适合作为本实验中的对抗训练内层攻击。

简要对比：

| 方法 | 主要目标 | 更适合做什么 |
|---|---|---|
| PGD | 固定预算内最大化损失 | 对抗训练、鲁棒性评估 |
| DeepFool | 寻找最小扰动 | 测量边界距离、分析模型脆弱性 |

## 12. 本实验的对抗训练实验设置

PPT 中的 PGD 对抗训练实验设置如下：

```text
训练集：50000 张
攻击：PGD-7
范数：L_inf
epsilon：8/255
训练轮数：80
优化器：SGD
学习率调度：40 / 60 轮衰减
```

损失函数是干净样本损失与对抗样本损失的加权和：

```math
(1-\lambda) CE_{clean} + \lambda CE_{adv}
```

其中：

```text
lambda = 0.5
```

这表示干净样本损失和对抗样本损失在总损失中权重相同。

这样设计的原因是：

- 如果只训练对抗样本，干净准确率可能下降过多。
- 如果只训练干净样本，模型不具备鲁棒性。
- 该设置用于在 Clean Acc 和 Robust Acc 之间取得相对平衡。

## 13. 如何判断防御是否有效？

不能只看一个弱攻击下的结果。

PPT 采用攻击强度阶梯：

```text
FGSM < PGD-20 < APGD
```

其中：

- FGSM 是单步攻击，较弱。
- PGD-20 是标准多步攻击。
- APGD 是更强的自适应攻击。

可靠的鲁棒性评估应满足：

```text
同一模型在更强攻击下，Robust Acc 不应升高。
```

也就是：

```text
FGSM Robust Acc >= PGD-20 Robust Acc >= APGD Robust Acc
```

如果强攻击下准确率反而更高，可能说明评估流程存在问题，或者攻击没有真正生效。

还要同时报告：

```text
Clean Acc + Robust Acc
```

只报告 Robust Acc 不够，因为鲁棒模型也可能通过牺牲大量干净准确率来获得表面上的鲁棒性。

## 14. 防御效果结果解读

PPT 中普通模型与鲁棒模型结果如下：

| 模型 | Clean Acc | FGSM Robust Acc | PGD-20 Robust Acc | APGD Robust Acc |
|---|---:|---:|---:|---:|
| 普通模型 | 88.53% | 3.57% | 0.00% | 0.00% |
| 鲁棒模型 | 86.25% | 55.62% | 45.82% | 45.30% |

### 14.1 鲁棒模型的对抗鲁棒性显著提升

普通模型在 PGD-20 和 APGD 下 Robust Acc 都是 0。

鲁棒模型在 PGD-20 下仍有：

```text
45.82%
```

在 APGD 下仍有：

```text
45.30%
```

说明对抗训练显著提升了模型在强攻击下的鲁棒性。

### 14.2 代价是 Clean Acc 略有下降

普通模型 Clean Acc：

```text
88.53%
```

鲁棒模型 Clean Acc：

```text
86.25%
```

下降约：

```text
2.3 个百分点
```

这是常见的鲁棒性与干净准确率权衡。

### 14.3 没有明显梯度混淆迹象

鲁棒模型结果为：

```text
FGSM: 55.62%
PGD-20: 45.82%
APGD: 45.30%
```

随着攻击增强，Robust Acc 依次下降。这符合预期，说明评估结果具有较高可信度。

## 15. DeepFool 视角下的防御效果

除了固定预算攻击，还可以用 DeepFool 从“边界距离”角度比较普通模型和鲁棒模型。

PPT 中结果大致为：

```text
普通模型：rho_adv ≈ 0.006，L2 ≈ 0.18
鲁棒模型：rho_adv ≈ 0.043，L2 ≈ 1.22
```

含义：

```text
诱导鲁棒模型产生误分类，需要约 7 倍大的扰动。
```

这说明对抗训练把决策边界从样本附近推远了。

这个结论和固定预算攻击结果一致：

- 固定预算攻击视角：鲁棒模型 Robust Acc 更高。
- 最小扰动视角：鲁棒模型需要更大扰动才会被误分类。

二者相互印证。

## 16. DeepFool 的优点与局限

### 16.1 优点

DeepFool 的优点包括：

- 扰动接近最小，通常非常小。
- 不需要人工指定攻击预算 `epsilon`。
- 几何解释清晰：寻找最近决策边界。
- 可以提供可比较的鲁棒性度量。

### 16.2 局限

DeepFool 也有局限：

- 默认是无定向攻击，不能指定目标类别。
- 样本通常停在边界附近，对量化、压缩等预处理较敏感。
- 攻击强度不一定超过 C&W 等优化型攻击。
- 不适合作为本实验中的对抗训练内层攻击。

## 17. FGSM、PGD、APGD、DeepFool、C&W 的方法对比

| 方法 | 核心机制 | 常见用途 |
|---|---|---|
| FGSM | 沿梯度符号执行单步更新 | 快速弱攻击、入门基线 |
| PGD | 在固定预算内多步最大化损失 | 对抗训练、标准鲁棒性评估 |
| APGD | 自适应步长与重启机制 | 更严格的鲁棒性评估 |
| DeepFool | 投影到最近决策边界 | 最小扰动评估、边界距离分析 |
| C&W | 直接优化最小扰动目标 | 高强度优化攻击、精细评估 |

可以按两类评估范式理解：

固定预算评估范式：

```text
FGSM / PGD / APGD
```

关注：

```text
在 epsilon 限制内，攻击能够在多大程度上降低模型鲁棒准确率？
```

最小扰动评估范式：

```text
DeepFool / C&W
```

关注：

```text
至少需要多大扰动才能改变模型预测？
```

## 19. 常见误解

### 误解一：干净准确率高就说明模型好

不一定。普通模型 Clean Acc 是 88.53%，但在 APGD 攻击下 Robust Acc 是 0.00%。这说明模型在自然样本上表现较好，但对对抗扰动非常敏感。

### 误解二：攻击成功率越高的方法一定越好

不一定。不同攻击目标不同。

APGD 目标是在固定预算内尽可能攻击成功。DeepFool 目标是寻找最小扰动。DeepFool 的价值在于扰动更小，可以反映决策边界距离。

### 误解三：DeepFool 攻击成功率高，所以适合训练

不一定。DeepFool 生成的扰动通常刚好跨越边界，扰动大小不统一，也没有固定预算，因此不适合作为本实验的训练内层攻击。

### 误解四：只看 Robust Acc 就够了

不够。必须同时看 Clean Acc。否则模型可能通过牺牲正常样本准确率来换取表面上的鲁棒性。

### 误解五：只用 FGSM 评估就够了

不够。FGSM 是较弱单步攻击。可靠评估需要至少包含更强的多步攻击，例如 PGD-20 和 APGD。

## 20. 最终结论

这份 PPT 后半部分的核心结论可以概括为：

```text
1. 普通 ResNet-18 在干净测试集上准确率较高，但对对抗扰动非常脆弱。
2. DeepFool 能用极小 L2 扰动诱导模型误分类，说明决策边界距离正常样本较近。
3. PGD 对抗训练可以显著提升固定扰动预算下的鲁棒性。
4. 鲁棒性提升会带来一定 Clean Acc 下降，这是常见的准确率-鲁棒性权衡。
5. 可靠评估必须同时报告 Clean Acc 和 Robust Acc，并使用强攻击进行验证。
6. DeepFool 的边界距离结果与 PGD/APGD 的固定预算评估相互印证。
```

一句适合放在讲解结尾的话是：

```text
DeepFool 用于测量模型离决策边界有多近，PGD 对抗训练用于把决策边界推远；
二者共同说明了普通模型的脆弱性以及对抗训练的防御效果。
```
